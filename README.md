# Abu Taha Portfolio

A premium dark React portfolio for software engineering placements, internships, and professional branding.

## Run locally

```bash
node server.js
```

Then open `http://localhost:4173`.

The app uses React from modern ESM CDN imports so it can run in this environment without a local `npm` installation. The `package.json` also lists standard React/Vite dependencies if you later want to convert it into a fully bundled Vite project.
